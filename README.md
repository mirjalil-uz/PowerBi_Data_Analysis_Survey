# PowerBi_Data_Analysis_Survey
Power BI dashboard analyzing data professionals' salaries, job roles, programming languages, career entry difficulty, and job satisfaction.
📌 Overview

This project is an interactive Power BI dashboard built to analyze survey data from data professionals.

The dashboard explores different aspects of the data industry, including job roles, salaries, programming language preferences, geographic distribution, career entry difficulty, and job satisfaction.

The goal of this project is to transform raw survey data into clear and interactive visual insights that can help understand trends within the data professional community.

🎯 Project Objectives

This analysis focuses on answering questions such as:

How many people participated in the survey?
What is the average age of survey participants?
Which data-related job roles have the highest average salaries?
What programming languages are most popular among data professionals?
Which countries have the most survey participants?
How difficult do people find entering the data industry?
How satisfied are data professionals with their salaries?
How satisfied are they with their work-life balance?
